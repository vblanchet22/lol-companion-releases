# LoL Companion — versions

Ce dépôt ne contient que les installeurs de **LoL Companion** (le code est dans un dépôt privé).

- Télécharge `LoL-Companion-Setup-x.y.z.exe` dans la dernière [release](../../releases/latest) et installe-le une fois : l'app se met ensuite à jour toute seule.
- `LoL-Companion-Portable-x.y.z.exe` : version sans installation, sans mise à jour automatique.
